# Antigravity CLI Instructions

Use the shared OpenStore AI rules.

Before editing, read:

1. `.ai/CONTEXT_MAP.md`
2. `AGENTS.md`
3. `.ai/README.md`
4. The applicable `.ai/skills/**/SKILL.md`
5. Task-relevant files from `docs/`
6. Target source and test files

Treat `.ai/skills/<skill-name>/SKILL.md` as a plain Markdown workflow. Native skill support is not required.

Keep `.ai/CONTEXT_MAP.md` updated when structure, entry points, standard commands, or important decisions change.

For more details, read `docs/AI_AGENT_PORTABILITY.md`.

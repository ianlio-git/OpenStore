# Agent Startup Routines

This folder contains short startup routines for AI coding CLIs.

Use them to avoid repeating long prompts. Pick the file that matches the tool and ask the agent to follow it.

---

## Quick usage

### Codex

```text
Follow .ai/agent-startup/codex.md.
Use create-feature-slice to implement CreateTenant.
```

### OpenCode

```text
Follow .ai/agent-startup/opencode.md.
Use create-feature-slice to implement CreateTenant.
```

### Antigravity CLI

```text
Follow .ai/agent-startup/antigravity.md.
Use create-feature-slice to implement CreateTenant.
```

### Any other agent

```text
Follow .ai/agent-startup/generic.md.
Use create-feature-slice to implement CreateTenant.
```

---

## Maintenance

Keep these files short. They should point to the source of truth instead of duplicating rules.

Source of truth:

- `AGENTS.md`
- `.ai/CONTEXT_MAP.md`
- `.ai/README.md`
- `.ai/skills/**/SKILL.md`
- `docs/`

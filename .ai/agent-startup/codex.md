# Codex Startup

Use this routine before editing.

1. Read `.ai/CONTEXT_MAP.md`.
2. Read `AGENTS.md`.
3. Read `.ai/README.md`.
4. Read the applicable `.ai/skills/<skill-name>/SKILL.md`.
5. Read only task-relevant docs, source files, and tests.
6. Use `.ai/CONTEXT_MAP.md` as the routing index to avoid unnecessary file loading.
7. Follow architecture, infrastructure, coding, testing, exception, reuse, and tenant-isolation rules.
8. Update `.ai/CONTEXT_MAP.md` when structure, entry points, standard commands, or important decisions change.
9. Do not claim completion until applicable build and tests pass, unless explicitly blocked.
